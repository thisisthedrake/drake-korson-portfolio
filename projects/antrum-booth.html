Antrum Booth

Modular trade show booth design showcasing centralized sensing technology

Project Details

Client: Antrum
Role: Experience Designer, 3D Modeler
Year: 2023
Services: Concept Design, 3D Modeling, Assembly Instructions

The Challenge

Antrum needed a big presence to showcase their centralized sensing tech—and it had to be modular enough to reconfigure for future shows. The booth needed to be impressive, functional, and easy to transport and assemble without requiring specialized installation teams.

The Solution

I took the concept design and detailed out how it would be built and assembled, creating a full 3D model that served as both a visualization tool and a construction guide. From there, I built a clear set of install instructions so the team could break it down, ship it, and set it up again without needing me onsite.

Key Features

  • Modular design for easy reconfiguration
  • Detailed 3D modeling for precise construction
  • Comprehensive assembly instructions
  • Portable and lightweight materials
  • Professional brand presentation
